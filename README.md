# aws-lab-04-ec2-apache-webserver

This project demonstrates launching an EC2 instance, installing Apache, and hosting a basic website.

## Steps I Took
- Launched EC2 instance (Amazon Linux)
- Connected via SSH
- Installed Apache (httpd)
- Started and enabled Apache service
- Configured security group (opened port 80)
- Verified website using public IP
